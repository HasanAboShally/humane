## The edit

The canonical Humane instructions were loaded and used for the website's sender-side editing task. A separate assistant received those instructions, the existing English copy, and the introduction as product evidence. It identified reader work caused by vague headings, repeated metaphors, and explaining the product after the slogans. Its suggestions were adapted into the page, not accepted as proof of human understanding.

The visible site now says what Humane is in its opening sentence: instructions for an existing AI assistant. “Example documents” means the original fictional documents used to write the displayed response; “Original notes” names the input to the drafting example. The tabs name the tasks: “Summarize documents” and “Rewrite a draft.”

Removed the language switch, Arabic route and font, locale dictionaries, repeated product-description strip, care-principles section, decorative caption, repeated sample-request strip, and footer slogan. The setup section separates copying instructions into a chat from installing through a private repository. Three short questions retain the privacy, compatibility, and accuracy limits. Cost and licensing are stated once beside setup.

The example source facts, figures, conditions, and source links remain. Shortening did not turn an estimate into an approval or a planned date into a confirmed one. The reading example explicitly limits itself to budget and timing rather than implying complete coverage of recruitment.

## Checks and limits

A fresh assistant read only the revised copy and page template. It could explain the product, distinguish originals from prewritten examples, and describe the chat-only route. It flagged one remaining access ambiguity; the chat instructions now explicitly say no installation or GitHub sign-in is needed to copy the instructions already on this page. This is an AI comprehension proxy, not a human-reader study.

All 27 repository/build checks and 30 Chromium/WebKit browser checks passed. The Arabic route and font return 404 and are absent from the built site; theme, keyboard, large-text, no-JavaScript, source-return, copy-failure, and real-download checks still pass. A scoped screenshot/copy review judged the preserved design and clearer text ready for the local preview. That result is not certification of universal accessibility or human comprehension.

The portable skill was not changed. Its 28-case model record and language-flexible behavior remain intact. Only the website is English-only. The repository remains private; Pages and public publication remain disabled.
