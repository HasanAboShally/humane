# Rough notes for a volunteer pilot

Fictional source. All details below are supplied for this illustration.

## Purpose

We want the project owner to approve trying a simpler workshop signup flow. Big picture: remove the repeated back-and-forth that volunteers currently need to get through signup. Don't imply that it is already built or that the test has run.

## Plan

Two-week pilot, 20 volunteers. Success means at least 16 finish signup without assistance. We need to observe completion, not claim it will improve by a certain percentage. The pilot does not prove that a full public rollout is ready.
