# Sender example: an approval request

This is an authored illustration based only on the [fictional notes](notes.md), not a recorded model result.

**Request:** “Use Humane to turn these notes into a short proposal for the project owner.”

## Example response

Please approve the approach for a two-week pilot of a simpler workshop signup flow with 20 volunteers. The aim is to find out whether volunteers can finish signup without the repeated back-and-forth they need today.

We would count the pilot as successful if at least 16 of the 20 volunteers finish without assistance. That would inform the next iteration; it would not establish readiness for a full public rollout.

The estimated cost is $8,000 excluding tax. The supplier quote is pending and the venue is not confirmed. **This request is for agreement on the pilot approach, not authorization to spend before the quote arrives.** A start date has not been agreed.

## What the reader should understand

The request distinguishes approach approval from spending approval. It keeps the success measure and uncertainties while adding no delivery promise, invented owner, deadline, or evidence of an improvement that has not been measured.
